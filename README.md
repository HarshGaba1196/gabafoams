# Gaba Foams

Website for Gaba Foams, Old Anaj Mandi, Nabha Gate, Patiala: mattresses, sofa cloth, sofa material, curtains and plastic chairs.

A single static page (`index.html`) with images in `img/`. No build step.

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173.
